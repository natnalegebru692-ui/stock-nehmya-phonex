# Stock Nehmya Phone Bot

Telegram phone stock and sales management bot for Ethiopia.

## Planned features
- Phone inventory with brand, model, RAM, storage, and IMEI
- Stock-in and stock-out tracking
- Sales with purchase price, selling price, and profit calculation
- IMEI search
- Customer and debt records
- Daily and monthly reports
- Admin and staff access
- Ethiopian Birr (ETB)

## Configuration
The bot will use environment variables:
- `BOT_TOKEN`: Telegram bot token (keep this secret)
- `ADMIN_IDS`: comma-separated Telegram user IDs allowed to administer the bot

Never commit bot tokens or passwords to GitHub.
